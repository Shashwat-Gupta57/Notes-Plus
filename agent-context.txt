[CORE VALUE PROPOSITION & ECOSYSTEM]
Notes+ is a high-performance, cross-platform productivity and privacy platform.
It combines a versatile note-taking canvas with zero-latency multi-device synchronization
and dual hidden security vaults.

Supported Platforms:
1. Android (Native Java 21, SQLite/Room, Android Material 3, Credential Manager, Background WorkManager).
2. Windows Desktop (Java 21 LTS, JavaFX 23, SQLite, native bundled JRE via jpackage, IExpress installer).
3. Web & PWA (Vanilla Modern ES Modules, Service Worker Cache, IndexedDB offline store, PWA installable).

---

[NOTE CAPABILITIES]
Notes+ supports six primary content types:
1. Rich Text & Markdown Documents: Headings (H1/H2/H3), Bold, Italic, Underline, Strikethrough,
   custom font color palette, adjustable leading (line-height: 1.2x to 2.4x), and adjustable kerning (letter-spacing).
2. Interactive Checklists / To-Dos: Drag-to-reorder, nested tasks, progress completion counters.
3. Infinite Visual Mind Maps: Node creation, relational links, color tagging, pan-and-zoom canvas.
4. Freehand Vector Sketches: Multi-tool stylus/finger ink, pressure smoothing, undo/redo stacks.
5. Voice & Audio Recordings: Inline waveforms, background audio capture, timestamp bookmarks.
6. Code & Raw Text Scratchpads: Monospace formatting, auto-indent, snippet organization.

---

[SECURITY ARCHITECTURE & DUAL HIDDEN WORLDS]
In addition to the public notepad canvas, Notes+ houses two covert spaces:
1. Encrypted Photo & Media Vault:
   - Protected by AES-256-GCM client-side encryption.
   - Master key derivation via PBKDF2 / Argon2id with unique per-vault salts.
   - Cloud backup encrypts attachments before upload to user-owned Google Drive (drive.file scope).
   - Zero-knowledge guarantee: Server never receives the encryption passphrase or unencrypted media keys.
2. Covert Chat Vault:
   - Secret peer-to-peer and group messaging disguised beneath gesture activation.
   - Separate access PINs and duress self-destruct mechanisms.
3. Note Locking:
   - Granular per-note PIN/Biometric lock.
   - Configurable auto-lock timeout policies (Immediate, 1 min, 5 min, 15 min, 30 min, 60 min, or App Exit).

---

[AUTHENTICATION & ACCOUNT SUBSYSTEM]
1. Dual-Authentication:
   - Google Sign-In (Credential Manager on Android, Identity token flow on Desktop/Web).
   - Email + Password with mandatory email verification before RTDB write permissions unlock.
2. Display Identifiers:
   - Global Unique Handle: `@username` (3-20 chars: `^[a-z0-9_.]{3,20}$`).
   - Profile Display Name and Avatar photo syncing.
3. Session Security:
   - Automatic silent token refresh via Firebase Auth REST API.
   - Hard account deletion cascading across `/users/{uid}`, `/profiles/{uid}`, `/notes/{uid}`, and `/usernames/{handle}`.

[DISTRIBUTED SYNC & DATABASE SCHEMA]
Firebase Realtime Database Endpoint:
  https://notes-plus-88985-default-rtdb.asia-southeast1.firebasedatabase.app

Key Hierarchy:
  /notes/{uid}/{noteId}
    - Content, title, type, modified timestamp, archive/trash flags.
  /users/{uid}/profile
    - username, displayName, email, syncFoldersArchive, created_at.
  /usernames/{username}
    - maps unique handle to UID.
  /stats/users/{uid}
    - checks/ (daily check-in pulse timestamps), platform identifiers, lastSeen.
  /feedback/{fid}
    - uid, username, displayName, email, rating (1-5), type (Bug Report / Feature / Praise),
      message, platform, version ("16.0"), ts, date.

Integrity Guarantees:
- Client-side optimistic persistence with Room / SQLite / IndexedDB.
- Offline dirty queues flushed sequentially upon network re-establishment.
- Concurrency handled via multi-path atomic updates (`updateChildren` / atomic patch).
- Telemetry respects user opt-out toggles and deduplicates heartbeats per installation UUID.
