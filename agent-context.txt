[WHAT IT IS]
A notes app with six kinds of note: text (edited as it looks, stored as Markdown), checklists,
journal days (mood, words, photos, videos), mind maps, sketches, and audio recordings.
Works offline and without an account. An optional account adds sync between devices and sharing.

[PLATFORMS]
- Android 7.0+: native app (Java, Room, Material 3), APK from the download page.
- Windows 10/11: native app (Java 21, JavaFX, SQLite), installer or portable ZIP, Java built in.
- Web: https://notes.talken.in/app/, installable as an app (PWA). Notes only (no private spaces).
- macOS, iPhone, iPad: through the web app, installed to the Dock / Home Screen.
- Linux: through the web app; a native Linux build is pending.

[BACKEND ZERO]
Notes+ runs no servers of its own and no server code:
- Website and web app: static files on GitHub Pages.
- Accounts: Firebase Authentication (Google, or email + password; email accounts must verify).
- Notes and sharing: Firebase Realtime Database; its security rules are the entire backend.
- Photos, videos, recordings: the user's own Google Drive, folder "Notes-plus" (drive.file scope).
- Downloads and updates: Cloudflare R2 and GitHub Releases, announced by version.json.
Everything runs on free tiers, so the app is free for users.

[SYNC]
- Syncs when a note is closed, when the app is left, and when it opens; never while typing.
- Each change carries a revision; the database accepts a change only on the revision it was based
  on. When two devices edited the same note, the last to sync wins.
- Folders and the archive sync with the account (since 16.6).
- Deleted notes are removed on all devices.

[SHARING]
- Share with people: a group note everyone edits (up to 20 people).
- Send to people: a read-only copy that follows the sender's edits.
- Share link: a read-only web page of the note's words (no files); deleting or locking the note
  takes it down.

[SECURITY]
- Notes in the database are protected by per-user access rules; they are not end-to-end encrypted.
- Locked notes: encrypted on the device with the note's own PIN, password or pattern (PBKDF2 +
  AES-GCM) before saving or syncing. A forgotten lock cannot be recovered.
- Private spaces (Android, Windows): opened by a gesture and a lock; files encrypted on the device
  with AES-256-GCM under a hardware-backed key; never sent to the Notes+ database. Not documented
  step by step on purpose.
- No ad or analytics SDKs. The website and web app keep visit logs (IP, place, system) for the
  administrator; see https://notes.talken.in/privacy.html.

[SETTINGS]
Open the account screen from the picture or initial at the top right of the notes screen.
It holds: sign in / sign out, Sync now, Photos and recordings (Google Drive), username, theme,
how long locked notes stay open, check for updates, feedback, delete account (Android, Windows),
install as an app (web), app logs (Android).

[UPDATES]
Every release is on releases.talken.in and GitHub Releases with SHA-256 checksums. The apps read
version.json: Android checks at most every 12 hours and verifies the checksum and signing key;
Windows checks at start and periodically; the web app checks when opened. Always install the
Android update over the existing app; uninstalling first deletes data kept only on that phone.
