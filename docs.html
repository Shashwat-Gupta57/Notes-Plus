Developer & User Documentation

Everything you need to know about Notes+: from tactile typography and visual markdown rendering to AES-256-GCM zero-knowledge encrypted vaults and distributed offline synchronization.

1. Overview & Ecosystem

Notes+ is a high-performance, cross-platform productivity and privacy platform. It combines a versatile note-taking canvas with zero-latency multi-device synchronization and dual hidden security vaults.

Unlike traditional monolithic note applications, Notes+ operates under an offline-first local persistence architecture:

  • Windows Desktop: Java 21 LTS with modular JavaFX 23, bundled JRE via jpackage, SQLite database storage, native IExpress installer.
  • Android: Native Java 21, SQLite with Android Room ORM, Material 3 tactile components, Credential Manager authentication, and WorkManager background task queues.
  • Web Application & PWA: Vanilla ES Modules with zero framework overhead, Service Worker caching, and IndexedDB local document persistence.

2. Installation & Quick Start

You can run Notes+ across Windows, Android, and Web browsers with seamless sync across all your devices:

Cross-Device Note: Notes+ account credentials allow all three platforms to synchronize in real time. You can view or edit notes offline on any device, and changes automatically reconcile once an Internet connection is detected.

Windows Desktop

Download Notes-Plus-Setup-16.4.exe or the portable standalone archive. The installer includes an embedded, isolated Java 21 runtime—no external Java installation is required.

Android Mobile

Install the release APK (Notes-Plus-16.5.apk). Supports Android 7.0 (Nougat) through Android 15+. Biometric unlock (Fingerprint / Face Unlock) can be enabled inside the Security settings.

Web App (PWA)

Visit notes.talken.in/app/ in any modern browser (Chrome, Edge, Safari, Firefox). You can install it directly as a standalone Progressive Web App (PWA) on your desktop or phone home screen.

3. Kinetic Typography & Formatting Engine

Notes+ text notes are edited as they look, like Word or WordPad, while they are stored as plain Markdown that every app reads:

  • Visual In-Editor Rendering: Text styled with bold, italic, underline, strikethrough, headings, colors, and lists renders with native visual typography—eliminating raw markdown symbols and asterisks from view.
  • Kerning (Letter Spacing): Real-time slider adjustment ranging from 0px to +6px (or -0.05 to +0.30 tracking on mobile), providing optimal readability for both compact notes and prominent titles.
  • Leading (Line Spacing): Dynamic line-height slider ranging from 1.2x to 2.4x for customizable vertical breathing room.
  • Color Palette: 6 curated vibrant accent hues (Default Ink, Electric Indigo, Cyber Emerald, Cyan Flare, Amber Gold, Rose Coral).
  • Render / Edit Toggle: Press Ctrl+R or click the 👁️ Render View button to switch between live editing mode and publication-grade rendered typography.

4. Dual Zero-Knowledge Encrypted Vaults

Behind a discrete gesture lies dual covert security vaults engineered for utmost privacy:

Secret Media & Photo Vault

Encrypted with authenticated AES-256-GCM encryption. Images and videos stored inside the vault are encrypted at rest on the local device before any data is written to disk or synced to the cloud. Decryption keys never leave device volatile memory and are cleared immediately upon vault auto-lock.

Covert Messaging Safe

A dedicated encrypted scratchpad and communication vault protected with independent secondary passkeys, timeout auto-wipes, and decoy camouflage states.

5. Real-Time Sync & Distributed Architecture

Notes+ employs an offline-first synchronization protocol backed by Firebase Realtime Database and local SQLite persistence:

  • Atomic Increments: Operational counters and heartbeat telemetry use server-evaluated atomic increments (ServerValue.increment) to prevent concurrency collisions.
  • Conflict Resolution: Timestamps paired with monotonic revision clocks guarantee deterministic merge ordering. Offline edits are queued in local SQLite tables and batched upon reconnection.
  • Scattered Storage Isolation: Database records are strictly scoped under authenticated User IDs (stats/users/$uid) with security rules enforcing zero cross-user visibility.

6. Security & Telemetry Disclosure

Notes+ is designed to protect your privacy:

  • Zero Third-Party Trackers: No Google Analytics, no Facebook SDKs, and no advertising cookies. The website keeps visit logs (IP address, place, system), described in the privacy policy.
  • Anonymous Daily Telemetry: Only anonymous system version counters (e.g., verifying whether a client is running v16.4 or Windows) are collected for update eligibility.
  • Full Opt-Out: Telemetry can be disabled entirely in Settings with a single switch. Account deletion executes a unified purge across database and storage records.
