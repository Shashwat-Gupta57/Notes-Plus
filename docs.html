Notes+ Documentation

How to install Notes+ on every platform, find every setting, and get the most from it, plus answers to common questions and how it all runs on Backend Zero.

1. Overview

Notes+ is a notes app for Android, Windows and the web: text notes, checklists, a journal, mind maps, sketches and voice recordings, synced between all your devices when you sign in. It works fully offline and without an account; signing in only adds sync and sharing.

Backend Zero. Notes+ runs no servers of its own. It is hosted for free, exists for free, and so every bit of it is free for you, and open source under the GPL-3.0. How that works →

2. Install

Windows

  1. Download Notes-Plus-Setup-16.6.exe from the download page and run it. It needs no Java: one is built in.
  2. If Windows SmartScreen says it doesn't recognise the app, choose More info → Run anyway. (The installer isn't code-signed yet; check its SHA-256 on the download page if you like.)
  3. Setup asks about a Desktop shortcut, the Start menu, and whether Notes+ should be your Default text editor for .txt and similar files.

Prefer no installer? The portable ZIP runs from any folder: unzip it and open Notes+.exe. Your notes live in %APPDATA%\Notes+ either way. To repair or remove Notes+, run Setup again and choose Repair or Uninstall.

Android

  1. On your phone, open the download page and tap Download APK.
  2. Open the downloaded file. Android asks once to allow installs from your browser: Settings → Allow from this source, then go back and tap Install.
  3. Updates are offered inside the app. Always install over the existing app; never uninstall first, or everything stored only on that phone is deleted with it.

Web, and installing it as an app

Open notes.talken.in/app. Without an account your notes are kept in this browser; sign in to sync them. To install it like an app (its own window, works offline):

  • Chrome / Edge (Windows, macOS, Linux, ChromeOS): the install icon at the right of the address bar, or in the app: Account → Install Web App (PWA).
  • Safari on macOS (Sonoma or later): File → Add to Dock.
  • iPhone / iPad: Safari → Share → Add to Home Screen.
  • Android: Chrome menu → Install app (or use the native APK).

macOS

There is no native Mac build. Install the web app as above (Chrome, Edge or Safari's Add to Dock): it opens in its own window from the Dock and Launchpad, works offline, and syncs with your phone and PC.

Linux

Native Linux build: pending. It's on the way. Until then, install the web app from Chrome, Chromium or Edge: it runs in its own window and syncs like the others. When the Linux build ships, it will be on releases.talken.in and on GitHub Releases like every other build.

3. Using Notes+

Kinds of note

Tap + New (Android, web) or the new-note button (Windows) and pick one:

  • Note: text edited as it looks, like Word or WordPad, with pictures.
  • List: a checklist; tick items, drag to reorder, add pictures.
  • Journal: one day, with a date, a mood, words, photos and videos.
  • Mind map: ideas around one or more central ideas; drag, link, tidy, add pictures and sub-text.
  • Sketch: freehand drawing.
  • Audio: a voice recording with its waveform.

A note's options

Open a card's menu: long-press it on Android, right-click it on Windows and the web (long-press on a touch screen).

OptionWhat it does
Pin to topKeeps the note first in the grid.
ColourTints the card and the editor.
Move to folder…Files it in a folder (or a new one). Folders show as chips above the grid.
ArchiveHides it from the grid; find it under the Archived chip and choose Unarchive.
DuplicateA copy of the note.
Send to people…Sends a read-only copy to people by @username; they see your edits.
Share link…A read-only web link anyone can open, words only (no files). Deleting or locking the note takes the link down.
DeleteRemoves it from all your devices.

Inside a note, the ⋮ menu (Android) or the editor's toolbar (Windows, web) also has Lock (a PIN, password or pattern for this note alone), Change lock / Remove lock, Share with people (edit together, up to 20 people), Wrap text (lists and mind maps) and Save a copy (for a note someone sent you).

Folders and the archive

The chips above the grid filter it: All, your folders, Shared with me, Archived, and each kind of note. New folder makes one; long-press (Android) or right-click (Windows, web) a folder chip to rename or remove it. Removing a folder keeps its notes. Since 16.6, folders and the archive follow you to every device you're signed in on.

Formatting text

Text notes look the way they read: bold is bold, a heading is big, a list has its bullets. Use the format bar (above the keyboard on Android, above the note on Windows and the web): B I U S, code, Style (normal, heading 1–3, quote), Colour, bullets, numbers, tasks, and line spacing. Or just type:

Type thisYou get
# , ## , ### at the start of a lineHeading 1, 2, 3
- or * A bulleted list
1. A numbered list
[] A task with a tick box
> A quote
**bold**, *italic*, ~~strike~~, `code`The formatting, marks hidden

Enter continues a list and an empty item ends it; Backspace at the start of a list item or heading makes it plain. A heading or quote is a style for the whole line, as in Word. Notes are stored as plain Markdown, the same on every platform.

5. Sync, accounts and sharing

  • Optional. Signed out, everything stays on the device. Signing in with Google or email adds sync; your @username is a public handle for sharing, never a login.
  • When it syncs. Never while you type: when you close a note, when you leave the app, and when you open it. Every device keeps working offline and catches up later.
  • Two devices, one note. Each change carries a revision number; the database accepts a change only on top of the version it was based on, so nothing is overwritten by accident. If two devices edited the same note, the one that syncs last wins.
  • Files (photos, videos, recordings) go to your own Google Drive, in a Notes-plus folder. The database holds only their list. Connect Drive from Account → Photos and recordings.
  • Sharing: Share with people makes a group note everyone edits (up to 20); Send to people gives them a read-only copy that follows your edits; Share link publishes a read-only page anyone with the link can open.

6. Private spaces

Notes+ also has private, encrypted spaces that open only with a gesture and a lock you choose. They are deliberately not explained step by step here: the less a page says about them, the better they hide. What matters for your safety:

  • Files in them are encrypted on the device with AES-256-GCM under a key kept in the phone's secure hardware store; they never go to the Notes+ database.
  • Their backups (a file you save, or your own Google Drive) are encrypted before they leave the device.
  • Wrong attempts lock the screen for longer and longer, up to an hour.

7. Releases and updates

Every release is published in two places, each file with its SHA-256 checksum:

  • releases.talken.in (Cloudflare R2): what the apps and this site download from.
  • GitHub Releases: the same files, with the release notes and the source they were built from.

The apps learn about a release from version.json: Android checks at most every 12 hours, Windows at start and every few minutes, the web app when it opens. Android verifies the download's checksum and signing key before installing. Android, Windows and the web share one version number.

Coming: a native Linux build, published to both places like the others.

8. FAQ

Is Notes+ really free?

Yes, with no ads, no subscription and no paid tier. Notes+ runs without servers of its own (see Backend Zero), so it costs almost nothing to keep alive. It's open source under the GPL-3.0.

Do I need an account?

No. Everything works on one device without one. An account adds sync between devices and sharing.

Where are my notes stored?

On your device, always. Signed in, their text also goes to the Notes+ database (Firebase), readable only by your account; photos and recordings go to your own Google Drive.

Can you read my notes?

Notes are protected by the database's access rules, not end-to-end encrypted, so the database owner could technically access them. For anything sensitive, use Lock on the note: a locked note is encrypted on your device with its PIN, password or pattern before it's saved or synced.

I forgot a locked note's PIN or password.

It can't be recovered: the note is encrypted with it, and nobody else has it. That's the point of the lock.

My folders don't show on my other device.

Update every device to 16.6 or later. Before 16.6, folders and the archive synced only where an option was on; 16.6 syncs them always and catches up on its first sync.

Windows says it protected my PC (SmartScreen).

The installer isn't code-signed yet, so Windows doesn't recognise it. Choose More info → Run anyway, and compare the file's SHA-256 with the one on the download page if you want to be sure.

How do I move to a new phone?

Sign in on the new phone with the same account: your notes, folders and files come down. Install the APK; don't restore an old one over it.

Does it work on Mac, Linux, iPhone or iPad?

Yes, through the web app, installed to the Dock or Home Screen (see Install). A native Linux build is pending.

Does it work offline?

Yes, everywhere. The web app, once opened, keeps working offline too. Changes sync when you're back online.

How do I delete my account and data?

Account → Delete account on Android or Windows. It removes everything stored online for that account: notes, username, profile and sharing.

I found a bug / I have an idea.

Account → Send Feedback & Review in any app, or open an issue on GitHub. On Android, Account → App logs lets you save logs to attach.

9. For developers: Backend Zero

No servers. No subscriptions. No compromises.
A state-of-the-art, cross-platform notes platform with zero backend code of its own: hosted for free, existing for free, and so free for everyone who uses it. Open source, GPL-3.0.

There is no Notes+ server, no API and no Cloud Functions. Every piece is a static file or a managed free tier:

PieceRuns onCost
Website and web appStatic files on GitHub Pages₹0
AccountsFirebase Authentication₹0
Notes, sharing, syncFirebase Realtime Database; the security rules are the whole backend: typed, size-capped fields, per-user access, revision checks, atomic username claims₹0 (Spark plan)
Photos, videos, recordingsEach user's own Google Drive (drive.file scope)₹0, on the user's own quota
Downloads and updatesCloudflare R2 (releases.talken.in) and GitHub Releases, announced by version.json₹0 (free tier, no egress fees)

Clients do all the work: conflict-safe sync with optimistic revisions, client-side encryption for locked notes and private spaces, and the same Markdown note format on Android (Java), Windows (JavaFX) and the web (vanilla JS).

Contribute: the code is on GitHub: master is Android, desktop is Windows, web is this site and the web app. Read CONTRIBUTING.md before opening a pull request.

10. Privacy and telemetry

  • No ad or analytics SDKs in any app: no Google Analytics, no Facebook SDK, no advertising cookies.
  • Apps count update checks per day and platform, and signed-in apps keep a small status row (platform, version, theme, last active day) so the developer can see which versions are in use.
  • This website and the web app keep visit logs (IP address and the place it maps to, system, referrer, time on page), readable only by the administrator. Details in the privacy policy.
