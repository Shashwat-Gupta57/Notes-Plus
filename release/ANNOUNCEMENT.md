## Notes+ for Windows 15.1: Duplication, Mind Map Enhancements, Real-Time Sync & Analytics

Pairs with Notes+ 15.1 for Android and Notes+ on the web (notes.talken.in/app).

### New in 15.1
- **Duplicate Notes**: Duplicate any note directly from the context menu with attachments and formatting preserved.
- **Checklist Auto-Save & Dirty Tracking**: Instant dirty tracking on item text edits, reordering, and checkbox toggling.
- **Mind Map Enhancements**: Multi-central idea additions, expanded boundary auto-wrapping for larger text, and zoom/copy/download options for mind map photos.
- **Real-Time Sync & Conflict Detection**: Automatic inactivity auto-save, live conflict detection against incoming remote edits, and instant note revocation handling when shared access is withdrawn.
- **Smooth Animations & List Formatting**: Smooth entrance and exit note transitions, plus automatic markdown bullet pointer (`* `) and numbered list (`1. `) detection.
- **Notes+ Analytics Dashboard**: Anonymous, zero-PII real-time telemetry dashboard on the web app.

### Install
1. Download `Notes-Plus-Setup-15.1.exe` below and run it. Already have Notes+? The app offers the update automatically. Your notes are kept intact.
2. If Windows SmartScreen says it doesn't recognise the app, choose **More info → Run anyway**.
