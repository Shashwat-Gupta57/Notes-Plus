## Notes+ for Windows 19.5: sync you can rely on

Pairs with Notes+ 19.5 for Android and Notes+ on the web (notes.talken.in/app).

### Fixed in 19.5
- **No more "Conflicted copy" notes.** When a note open here had unsaved edits and a newer version arrived, a copy was made on every sync, and for a shared (group) note the copy kept the group's identity and could overwrite it. Now the edit made here simply wins, as designed, and any such stray copy becomes a note of your own.
- **A note left open syncs.** Edits to a note still open in a window go up as soon as they're saved, instead of waiting until it's closed. Changes from your other devices still never overwrite a note you're editing.

### Also in 19.4
Reminders for list items, a date pane with Apply and a time wheel, calmer mind map colours, and the fixes for lists opening with blank gaps and for Enter in the `[[` list.

### Install
1. Download `Notes-Plus-Setup-19.5.exe` below and run it. Already have Notes+? The app offers the update automatically. Your notes are kept intact.
2. If Windows SmartScreen says it doesn't recognise the app, choose **More info → Run anyway**.
