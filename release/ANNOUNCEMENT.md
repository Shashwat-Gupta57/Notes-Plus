## Notes+ for Windows 15.2: Startup Auto-Updates & In-App Download Tracking

Pairs with Notes+ 15.2 for Android and Notes+ on the web (notes.talken.in/app).

### New in 15.2
- **Automatic Startup Update Checks**: The app checks for new updates on startup and notifies you directly.
- **In-App Download Progress**: Real-time progress tracking with percentage and byte indicators during updates.
- **Immediate Install Prompt**: Prompts to update or restart into the newest version the moment a download finishes.
- **Web App Auto-Detection**: Notifies users in the browser when a new update is ready to reload.
- **Note Duplication & Real-Time Sync**: Everything from v15.1 including one-click duplication, checklist auto-save, mind map picture zoom, and conflict detection.

### Install
1. Download `Notes-Plus-Setup-15.2.exe` below and run it. Already have Notes+? The app offers the update automatically. Your notes are kept intact.
2. If Windows SmartScreen says it doesn't recognise the app, choose **More info → Run anyway**.
