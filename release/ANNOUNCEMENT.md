## Notes+ for Windows and Linux 19.7

Pairs with Notes+ 19.7 for Android and Notes+ on the web (notes.talken.in/app).

### New in 19.7
- **Notes+ for Linux**: the same desktop app, as a `.deb` (Ubuntu, Debian, Mint), an AppImage (any distribution) and a `.tar.gz`.
- **Hidden notes have a lock**: they open with the main lock you already use (or the one set on another device), and you can give them their own from the hidden view.
- **Updates no longer pile up**: only the newest downloaded update is kept; older copies in `%LOCALAPPDATA%\Notes+\updates` are deleted.

### Also from 19.5
No more "Conflicted copy" notes, and a note left open still syncs.

### Install
- **Windows**: download `Notes-Plus-Setup-19.7.exe` below and run it. Already have Notes+? The app offers the update automatically. If SmartScreen warns, choose **More info → Run anyway**.
- **Linux**: `sudo apt install ./notes-plus_19.7_amd64.deb`, or make the AppImage executable and run it.
