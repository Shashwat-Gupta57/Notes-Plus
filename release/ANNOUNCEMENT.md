## Notes+ for Windows 12.0 — backups you can hold

Pairs with Notes+ 12 for Android, and with Notes+ on the web (notes.talken.in/app), new in 12.

### New
- **Export a note** (⋮ → Export…) as one `.npnote` file: its text, title, colour, pictures,
  recordings and lock, all in one. Keep it on a USB stick; opening it with Notes+ brings the note
  back exactly as it was (as a new note, so it never overwrites the one you have).
- **Deleting a linked note deletes its file too.** A note saved from a .txt file now takes the file
  with it when you delete it (on this PC or on your phone), into the Recycle Bin, so a mistake can
  be undone there.
- **Notes+ on the web.** Your notes in any browser, synced with this PC and your phone; a note
  locked here opens there with the same lock.

### Install
1. Download `Notes-Plus-Setup-12.0.exe` below and run it. Already on 11.0? Notes+ offers the update
   by itself. Your notes are kept (they live in `%APPDATA%\Notes+`).
2. If Windows SmartScreen says it doesn't recognise the app, choose **More info → Run anyway**.
